## 🚀 Proyectos destacados

### 💰 Finanzas App
**Proyecto Final de DAM | Aplicación multiplataforma**

Aplicación para Android y Windows orientada a la gestión de finanzas personales, con un backend independiente y una arquitectura organizada en cuatro capas.

**Funcionalidades principales:**
- Gestión de ingresos y gastos por categorías.
- Objetivos financieros con seguimiento en tiempo real.
- Visualización de estadísticas y gráficas.
- Grupos compartidos con ranking de gastos.
- Autenticación mediante JWT.

**Stack:** `C#` `ASP.NET Core` `.NET MAUI` `MySQL` `Docker`

**Infraestructura:** Base de datos alojada en Aiven y API desplegada mediante Docker en Railway.

### 📦 GestionAlmacenPDA
**Proyecto de prácticas | Aplicación Android**

Aplicación para dispositivos PDA destinada a digitalizar y facilitar las operaciones habituales de un almacén.

**Funcionalidades principales:**
- Control de entradas, salidas y stock.
- Integración con lector nativo de códigos de barras.
- Gestión de usuarios con roles de administrador y operario.
- Histórico de movimientos de inventario.
- Reactivación de productos inactivos.

**Aportación personal:** Además de los requisitos iniciales, diseñé la estructura de la aplicación e incorporé funcionalidades adicionales de gestión de usuarios y productos.

**Stack:** `Kotlin` `Jetpack Compose` `Room` `SQLite` `Hilt`

### 🏠 ERP Inmobiliaria
**Desarrollo de módulo personalizado para Odoo**

Módulo ERP orientado a centralizar la gestión de una inmobiliaria y sus procesos habituales.

**Funcionalidades principales:**

- Registro de visitas y operaciones inmobiliarias.
- Validaciones de negocio personalizadas.
- Vistas de tabla, Kanban y calendario.

**Stack:** `Python` `Odoo` `XML`
