## 🚀 Proyectos destacados

### 💰 [Finanzas App](https://github.com/Roberto-GS/finanzasapp-dam)

**Proyecto Final DAM | Android & Windows**

Aplicación multiplataforma para la gestión de finanzas personales, desarrollada con un backend independiente y una arquitectura organizada en cuatro capas.

**Funcionalidades:**
- Gestión de ingresos y gastos por categorías.
- Objetivos financieros con seguimiento en tiempo real.
- Estadísticas y gráficas.
- Grupos compartidos con ranking de gastos.
- Autenticación mediante JWT.

**Tecnologías:** `C#` `ASP.NET Core` `.NET MAUI` `MySQL` `Docker`

**Infraestructura:** API desplegada en Railway mediante Docker y base de datos alojada en Aiven.

### 📦 [GestionAlmacenPDA](https://github.com/Roberto-GS/GestionAlmacenPDA)

**Proyecto de prácticas | Android**

Aplicación para dispositivos PDA orientada a digitalizar las operaciones habituales de un almacén.

**Funcionalidades:**
- Control de entradas, salidas y stock.
- Integración con lector nativo de códigos de barras.
- Gestión de usuarios con roles diferenciados.
- Histórico de movimientos.
- Reactivación de productos inactivos.

**Aportación personal:** Diseñé la estructura de la aplicación e incorporé funcionalidades adicionales de gestión de usuarios y productos, más allá de los requisitos iniciales.

**Tecnologías:** `Kotlin` `Jetpack Compose` `Room` `SQLite` `Hilt`
