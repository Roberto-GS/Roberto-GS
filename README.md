## Hola, soy Roberto 👋

**Desarrollador de Software · Backend & Multiplataforma**

Técnico Superior en Desarrollo de Aplicaciones Multiplataforma (DAM) y con experiencia práctica construyendo aplicaciones completas desde el backend y el cliente hasta el despliegue. 

No me limito a implementar las tareas que se me asignan: busco formas más eficientes de resolverlas e identifico casos no contemplados y necesidades funcionales durante el desarrollo.

Mi objetivo es que las aplicaciones respondan a las necesidades de un entorno real, reduciendo los errores y problemas para el usuario final.
He trabajado con C#/.NET (ASP.NET Core, EF Core), Kotlin/Android y Python/Odoo, siempre con arquitecturas por capas y estructuras orientadas al mantenimiento y evolución del software.



**Tecnologías💻**

· _Lenguajes:_ C#, Java, Python y Kotlin

· _Backend:_ ASP.NET Core, EF Core, REST APIs, JWT

· _Multiplataforma y móvil:_ Android, .NET MAUI, Jetpack Compose

· _Bases de datos:_ PostgreSQL, MySQL, SQLite, SQL

· _Arquitectura y patrones:_ Clean Architecture, MVVM, Repository Pattern

· _ERP:_ Odoo

· _Herramientas y despliegue:_ Git, GitHub, Docker, Railway, Aiven



**Proyectos Principales🗃️**
Finanzas App - Proyecto Final DAM
Una plicación multiplataforma (Android y Windows) para gestionar las finanzas personales: ingresos y gastos por categorías, objetivos con seguimiento en tiempo real, gráficas y grupos compartidos con ranking de gastos. API REST con ASP.NET Core y JWT, cliente en .NET MAUI y arquitectura en cuatro capas (Core, Infrastructure, API y UI). Base de datos en Aiven y despliegue con Docker en Railway.

Tecnologías: C# · ASP.NET Core · .NET MAUI · MySQL · Docker

GestionAlmacenPDA - Proyecto de Prácticas
Una App Android para la gestión de entradas, salidas y stock mediante PDAs y con lector de código de barras nativo. Kotlin · Jetpack Compose · SQLite.

ERP Inmobiliaria - Odoo
Un ERP a medida para centralizar los inmuebles, propietarios, clientes y visitas, con validaciones de negocio propias. Vistas de tabla, Kanban y calendario para gestionar las operaciones y las visitas
